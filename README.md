# Application Security Portfolio

Hands-on application security, API security, and penetration testing portfolio.

This repository documents practical learning in authorized labs and intentionally vulnerable training environments. Each report should explain the scope, method, evidence, impact, and remediation.

## Focus areas

- Web application security
- API security
- Vulnerability validation and reporting
- Secure remediation guidance

## Training environments

- PortSwigger Web Security Academy
- OWASP crAPI
- Metasploitable 2

## Repository contents

- `PortSwigger/` — lab notes and a progress index
- `OWASP-crAPI/` — API security notes and the BOLA report
- `Metasploitable2/` — notes from the intentionally vulnerable training VM
- `Documentation/` — testing methodology and tools

## Progress

Work is documented as it is completed. An empty template or planned report does not mean a vulnerability has been confirmed. See each section for its current status.

## Responsible use

All testing described here is limited to systems I own or have explicit permission to assess, including designated training labs. Do not use these notes to test systems without authorization.
