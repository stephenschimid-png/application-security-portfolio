# PortSwigger Web Security Academy

This section is for notes from PortSwigger Web Security Academy labs. Add a report only after completing the lab, and record the lab name, vulnerability class, key learning, and a sanitized proof of completion where appropriate.

See [Lab Index](Lab-Index.md) for the tracking list.

## Reporting guidelines

- Mark a lab complete only after personally completing it.
- Do not include account credentials, session cookies, or other secrets.
- Keep evidence limited to the authorized training environment.
